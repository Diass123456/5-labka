# «Фитнес клубты басқару» - Абонемент сатып алу (Sequence Diagram)

```mermaid
sequenceDiagram
    autonumber
    actor Клиент as Клиент
    participant Жүйе as Фитнес клуб жүйесі
    participant Модуль as Абонемент модулі
    participant Төлем as Төлем жүйесі
    participant БАЗА as Мәліметтер базасы

    Клиент->>Жүйе: 1. Жүйеге кіру (логин, құпия сөз)
    Жүйе->>БАЗА: 2. Деректерді тексеру
    БАЗА-->>Жүйе: 3. Жүйеге кіру сәтті / қате
    
    Клиент->>Жүйе: 4. Абонементтерді қарау
    Жүйе->>Модуль: 5. Абонемент тізімін сұрау
    Модуль-->>Жүйе: 6. Тізімді жіберу
    Жүйе-->>Клиент: 8. Абонементтер тізімі

    Клиент->>Жүйе: 9. Абонементті таңдау
    Жүйе->>Модуль: 10. Таңдалған абонемент туралы сұрау
    Модуль->>БАЗА: 11. Абонемент мәліметтері
    БАЗА-->>Жүйе: 12. Мәліметті қайтару

    Клиент->>Жүйе: 14. Төлем әдісін таңдау (Карта/Kaspi QR)
    Жүйе->>Төлем: 15. Төлем әдісін өңдеу
    Төлем-->>Жүйе: 16. Төлем әдісі қабылданды

    Клиент->>Жүйе: 18. Төлем жасау
    Жүйе->>Төлем: 19. Төлемді өңдеу (Банк)
    Төлем-->>Жүйе: 22. Төлем нәтижесі (Сәтті)

    alt Төлем сәтті
        Жүйе->>Модуль: 24. Абонементті белсендіру
        Модуль->>БАЗА: 25. Мартебесін жаңарту
        Жүйе-->>Клиент: 27. Сатып алуды растау (Чек, абонемент нөмірі)
    else Төлем сәтсіз
        Жүйе-->>Клиент: 30. Қате туралы хабарлама
    end
